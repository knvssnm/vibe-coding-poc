Pods per node

Single-workload capacity

First reserve the buffer on each node. Then pods per node = min(floor(usable CPU / pod CPU), floor(usable memory / pod memory), pod slots). For one workload, nodes = ceil(replicas / pods per node). Mixed workloads are packed as complete pods, checking both resources on every node. Zero requests do not constrain that resource.

Each card evaluates a workload on an otherwise empty node, independently of other workloads and without capping capacity by its replica count.

Add a workload to inspect its per-node capacity.

Pod placement preview

A planning estimate, not a scheduling guarantee. Uses resource requests (not limits) and a best-fit decreasing placement heuristic. Nodes are identical and dedicated to these workloads. Subtract existing workloads and DaemonSet resources from allocatable inputs before planning. Affinity, taints, topology, storage, rollout surge and node failures are not modeled. A 20% resource buffer does not guarantee survival of a node failure.
